# Simon Says Arduino

## Description
A Simon Says memory game built with Arduino Uno. The game shows a sequence of LEDs and the player must repeat the sequence using buttons. Each round adds a new LED to the sequence.

## Components
- Arduino Uno
- 4 LEDs (blue, yellow, green, white)
- 4 push buttons
- 4 resistors (100Ω)
- 1 buzzer
- 1 LCD 16x2 display
- Breadboard and jumper wires

## How to play
1. The Arduino shows a sequence of LEDs
2. Press the buttons in the same order
3. Each round adds one more LED to the sequence
4. If you press the wrong button, the LEDs flash and the game restarts
5. The LCD shows the current level and "Perdiste!" when you lose

## Features
- Random sequence generation
- Sound feedback with buzzer
- LCD display showing level and game over message
- Automatic restart after losing
